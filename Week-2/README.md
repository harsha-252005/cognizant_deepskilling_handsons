# Week 2 — TDD, Logging, Spring Core, and Maven

Mandatory exercises are grouped as follows:

- `TDD-and-Mockito`: JUnit setup, assertions, AAA fixtures, Mockito stubbing,
  and interaction verification.
- `Logging`: SLF4J error and warning-level logging.
- `Spring-Core-and-Maven`: IoC configuration, constructor/setter DI, and a
  Maven project structure.

The existing Spring Boot, Hibernate, and Spring Data practice folders remain
available as supplementary exercises; the canonical mandatory JPA/REST work is
listed under Week 3.
