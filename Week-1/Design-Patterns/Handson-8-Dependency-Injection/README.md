# Handson-8: Dependency Injection Pattern _(coming soon)_

## Problem Statement
Implement manual Dependency Injection (without Spring) to understand
the principle that Spring automates.

## Objectives
- Understand DI without a framework
- Program to interfaces, not implementations
- Prepare for Spring @Autowired and @Component

## How to Compile & Run
```bash
cd src
javac *.java
java DIDemo
```
