# Handson-6: Decorator Pattern _(coming soon)_

## Problem Statement
Implement a coffee shop system where condiments (Milk, Sugar, Whip) are
dynamically added to a base coffee object without subclassing.

## Objectives
- Understand the Decorator structural pattern
- Add behavior dynamically at runtime
- Apply composition over inheritance

## How to Compile & Run
```bash
cd src
javac *.java
java DecoratorDemo
```
