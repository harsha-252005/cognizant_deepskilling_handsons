# Handson-4: Observer Pattern _(coming soon)_

## Problem Statement
Implement a stock price alert system where multiple observers (Email, SMS, Mobile)
are automatically notified when a stock price changes.

## Objectives
- Understand the Observer behavioral pattern
- Implement publish-subscribe mechanism
- Decouple subject from observers

## How to Compile & Run
```bash
cd src
javac *.java
java ObserverDemo
```
